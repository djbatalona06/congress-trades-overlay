# Capitol Tape brand files

The mark pairs a disclosure strip with a rising signal. The colors are slate (`#172536`), off-white (`#F7F8F6`), and muted teal (`#4D9A88`).

- `capitol-tape-lockup.svg` — horizontal logo
- `capitol-tape-icon.svg` — standalone mark
- `favicon.svg` — tab icon with a solid slate background
- `apple-touch-icon.png` — 180 px app icon
- `favicon-mono.svg` — one-color fallback
- `tab-preview.png` — light and dark browser-tab preview
