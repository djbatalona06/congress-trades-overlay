# Extension 1.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship extension 1.2.0: every trade feature free, Pro paused behind a waitlist, an official-record link on every trade row, and no money asks next to trade data.

**Architecture:** Bottom to top: data helpers in `lib/` first, then shared components, then the popup, then copy, version and checks. The ExtensionPay code stays for spec 2 but stops gating anything, and the panel-to-payment message path is deleted.

**Tech Stack:** WXT 0.21, React 19, TypeScript, Vitest + jsdom, `wxt/testing/fake-browser`.

**Spec:** `docs/superpowers/specs/2026-10-18-publication-pivot-design.md` (section 3, and the extension rows of section 6).

## Global Constraints

- Version `1.2.0` in `package.json` (WXT reads the manifest version from it).
- Release note: "Watchlist and new-filing alerts are now free for everyone. Each trade links to its official record."
- House search page: `https://disclosures-clerk.house.gov/FinancialDisclosure/ViewSearch`. Senate search page: `https://efdsearch.senate.gov/search/`.
- Waitlist URL: `https://capitol-tape.pages.dev/extension/#waitlist`.
- Every external link: `target="_blank" rel="noopener noreferrer"`.
- Panel, pop-out and notifications contain nothing matching `/upgrade|\bpro\b|donat|subscribe|pricing|waitlist|newsletter/i`.
- Disclaimer text, Bargo as the data source, the limit message, the edge tab, the pop-out and the update gate stay as they are.
- `site/index.html` is not touched by this plan (it has uncommitted user edits and is rebuilt in the site plan).

## Findings that shape the plan

- Live Bargo check (2026-10-19, `GET /trades/NVDA`): `filing_portal` is always the portal home, `https://disclosures-clerk.house.gov/FinancialDisclosure` for House rows and `https://efdsearch.senate.gov/search/` for Senate rows. It is never a single filing. So rows link to the chamber search page, labelled "Search official records". A specific document URL (a `.pdf`, or an eFD `/search/view/` page) gets "Official record", so the code is ready if Bargo ever adds one.
- `requestPaymentPage` / `cto/open-payment` exist only for the panel's "Upgrade to Pro" link. They are deleted.

## Review Focus

1. Trade with `chamber: null` and `sourceUrl: null` must still render official links: both House and Senate search links. Test in Task 1.

3. A user who paid under 1.1.0, opening the popup offline, must still see the "Couldn't reach the payment server" message and Try again, not a blank Plan tab. Test in Task 4.
4. A user with more than 3 tickers saved from Pro days must keep all of them and be able to add more with no Pro status. Test in Task 2.
5. Alerts must keep working when the ExtensionPay status was never written (fresh install). Test in Task 3.

```ts
export const HOUSE_SEARCH_URL = 'https://disclosures-clerk.house.gov/FinancialDisclosure/ViewSearch';
export const SENATE_SEARCH_URL = 'https://efdsearch.senate.gov/search/';

export interface RecordLink {
  url: string;
  label: string;
}

// Bargo's filing_portal is the portal home today; a single filing is a PDF or an eFD view page.
const isSpecificFiling = (url: string) => /\.pdf$/i.test(url) || /efdsearch\.senate\.gov\/search\/view\//.test(url);

function chamberOf(trade: Pick<CongressTrade, 'chamber' | 'sourceUrl'>): Chamber | null {
  if (trade.chamber) return trade.chamber;
  if (trade.sourceUrl?.includes('senate.gov')) return 'senate';
  if (trade.sourceUrl?.includes('house.gov')) return 'house';
  return null;
}

/** Where to read the official record of a trade. Never empty. */
export function officialRecordLinks(trade: Pick<CongressTrade, 'chamber' | 'sourceUrl'>): RecordLink[] {
  const url = trade.sourceUrl;
  if (url?.startsWith('https://') && isSpecificFiling(url)) return [{ url, label: 'Official record' }];
  const chamber = chamberOf(trade);
  if (chamber === 'house') return [{ url: HOUSE_SEARCH_URL, label: 'Search official records' }];
  if (chamber === 'senate') return [{ url: SENATE_SEARCH_URL, label: 'Search official records' }];
  return [
    { url: HOUSE_SEARCH_URL, label: 'House records' },
    { url: SENATE_SEARCH_URL, label: 'Senate records' },
  ];
}
```

export function WatchButton({ ticker, platform }: { ticker: string; platform: Platform | null }) {
  const [watchlist, setWatchlist] = useState<WatchlistItem[] | null>(null);

  useEffect(() => {
    getWatchlist().then(setWatchlist);
    return watchWatchlist(setWatchlist);
  }, []);

  if (!watchlist) return null;
  const watching = watchlist.some((item) => item.ticker === ticker);

        {watching ? `Watching ${ticker}` : `Watch ${ticker}`}
      </button>
    </div>
  );
}
