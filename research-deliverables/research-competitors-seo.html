Where Capitol Tape can win

  • It sits on the chart you already use; web trackers make you switch tabs.
  • Second-monitor pop-out and (planned) split graph panel - none of the listed rivals advertise this.
  • Plain-language, read-only, no tracking, no affiliate codes: a trust story.
  • Cheapest paid tier of the set at $8, but the daily lookup limit is its weak point.

Chrome Web Store policy note

Adding user analytics to the extension would trigger the store's user-data disclosure and Limited Use rules. The dashboard spec avoids this by tracking nobody. Source: Chrome Web Store Limited Use policy. Re-read the live text before any change.
