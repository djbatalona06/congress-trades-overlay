Dual display spec

Pop-out split with a trade list and a graph panel. Design only.

Decision made: a side-by-side split inside the pop-out window. The broker page layout is never touched (already rejected in the PRD delta as fragile across four sites).

Wireframe

Draggable divider (green). Below about 560px wide it becomes two tabs: List | Graphs.

Behaviour

  • Default pop-out stays 380x720, so it opens as tabs; widen it and the split appears. Width is already saved via lib/popout.ts.
  • The graph panel follows the same local:currentTicker as the list (Panel.tsx:40-47).
  • The on-page drawer keeps the list only; "open graphs" button opens the pop-out.
