Rules

  • Only data already fetched; no extra Bargo calls. Respect the daily budget (lib/budget.ts).
  • Per ticker first; watchlist rollup uses cached rows only (Pro).
  • Every chart has a data-table fallback and keyboard focus (WCAG AAA tokens already enforced by tests/a11y.test.tsx).
  • Empty, loading, rate-limited and error states copied from components/TradesBody.tsx.
